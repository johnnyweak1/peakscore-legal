# peak-score.com

Built static site for [Peak Score](https://www.peak-score.com) — training readiness app for Apple Watch.

This repository contains the **production build output only** (static HTML/CSS/images generated with [Astro](https://astro.build)). Source code lives in a private repository.

Deploy = replace repo contents with fresh build output and push to `main`. GitHub Pages serves `main` / (root); `.nojekyll` is required so the `_astro/` asset folder is served.
